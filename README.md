# column_app

公開しているコンテンツをカテゴリごとにまとめています。

## 📚 コンテンツ

- **AI記事まとめ** - ローカルAIまわりの気になるニュースをまとめています。
- **GitHub用語辞典** - 初心者向けのGitHub・Git用語を、わかりやすく解説しています。
- **LTX** - 動画生成AI「LTX」シリーズのしくみを解説する記事です。
- **ミニアプリ** - ブラウザだけで動く、ちょっとしたツール・ミニアプリ集です。
- **UE** - Unreal Engineのマテリアルまわりの小技・Tipsをまとめています。

## 🚀 ローカル開発

```bash
# リポジトリをクローン
git clone https://github.com/CenterV80/column_app.git
cd column_app

# ローカルサーバーを起動
python3 -m http.server 8000

# ブラウザで確認
# http://localhost:8000
```

詳細は [DEPLOYMENT.md](DEPLOYMENT.md) を参照してください。
