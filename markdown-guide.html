📝 Markdown記法ガイド

簡単なものから順に並べた、書き方の早見表

🌱 初級：まずはこれだけ

見出し（#）

#の数で見出しレベルを表します。1つで一番大きい見出し、増えるほど小さくなります。
# 見出し1 ## 見出し2 ### 見出し3
注意： #の後ろに半角スペースを1つ入れます。

段落と改行

空行を1つ入れると新しい段落になります。同じ段落内で改行したいときは、行末に半角スペースを2つ入れます。
1行目 2行目（行末にスペース2つ） ここから新しい段落

強調（太字・斜体）

アスタリスク*やアンダースコア_で文字を囲むと、強調表示になります。
*斜体* または _斜体_ **太字** または __太字__ ***太字斜体***

リスト（箇条書き・番号付き）

箇条書きは-・*・+のいずれか、番号付きリストは数字と.を使います。
- 項目A - 項目B - 項目Bの子項目 1. 最初の手順 2. 次の手順
ポイント： 子項目は半角スペース2〜4個でインデントします。

🎓 中級：もう少し使いこなす

リンク

[表示文字](URL)の形式で書きます。
[GitHub](https://github.com)

画像

リンクの先頭に!を付けると画像になります。
![代替テキスト](画像のURL)

引用（>）

行頭に>を付けると引用ブロックになります。>を重ねると引用の中に引用を作れます。
> これは引用です。 >> これは引用の中の引用です。

水平線

-・*・_を3つ以上単独の行に並べると、区切り線になります。
---

コード（インライン・ブロック）

短いコードはバッククォート1つで、複数行のコードはバッククォート3つで囲みます。言語名を添えるとシンタックスハイライトが付きます。
`インラインコード` ```python def hello(): print("Hello") ```

🔬 上級：表現の幅を広げる

テーブル（表）

|で列を区切り、1行目の下にハイフンの行を入れてヘッダーとの区切りにします。:の位置で揃え方を指定できます。
| 名前 | 説明 | | --- | --- | | # | 見出し | | - | リスト | | 左揃え | 中央揃え | 右揃え | | :--- | :---: | ---: | | a | b | c |

タスクリスト（チェックボックス）

リストの項目に[ ]または[x]を付けると、チェックボックス付きのリストになります。
- [x] 完了したタスク - [ ] 未完了のタスク
注意： GitHub Flavored Markdownなど、一部の環境のみ対応しています。

脚注

[^1]のような記号を本文に置き、別の行で内容を定義します。
これは本文です[^1]。 [^1]: これが脚注の内容です。
注意： 対応していない環境もあります。

エスケープ

*や#などの記号をそのまま表示したいときは、直前に\（バックスラッシュ）を付けます。
\*これは強調されません\*
