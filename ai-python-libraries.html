🐍 AI画像・動画生成を支えるPythonライブラリまとめ

ComfyUIやLTX、FLUX系のソースコードに登場するライブラリを役割ごとに整理しました

⚙️ 基盤・実行環境

PyTorch

テンソル計算とニューラルネット実行のための基盤ライブラリです。GPU上で行列演算を行う「エンジン」部分にあたり、ComfyUIも中身はPyTorchで動いています。

NumPy

CPU上での配列・数値計算ライブラリです。PyTorch登場以前からある汎用ツールで、画像の前処理(リサイズ、正規化など)でよく使われます。GPUには非対応です。

📦 モデルの実装・読み込み系

Transformers(Hugging Face)

主にテキストエンコーダー(CLIP、T5など)、つまり「言葉をベクトルに変換するモデル」の実装を提供するライブラリです。

Diffusers(Hugging Face)

拡散モデル(Stable Diffusion、FLUXなど)の実装・パイプラインを提供するライブラリです。画像・動画生成本体を担当します。

Safetensors

モデルの重み(パラメータ)を安全かつ高速に保存・読み込みするためのファイル形式・ライブラリです。計算そのものには関与しない、あくまで「入れ物」です。
紛らわしい名前の元凶： 「Transformer」(単数、アーキテクチャ名)は2017年の"Attention is All You Need"論文由来のニューラルネット構造そのもの。CLIP、T5、拡散モデル内のU-NetやDiTもこの構造を使っています。一方「Transformers」(複数、ライブラリ名)は、上記アーキテクチャを実装したHugging Faceのライブラリの製品名です。

🖥️ GPU処理まわり

CUDA

NVIDIAが作った、GPUに直接計算をさせるための基盤の仕組みです。PyTorchなどほとんどのAI系ライブラリはこの上に乗って動いています。

cuDNN

CUDAの上で、ニューラルネットで頻繁に使う計算だけを専用に高速化する部品です。CUDAが土台の道路だとすると、cuDNNはその上を走る専用の高速レーンです。

xFormers(Meta製)

注意機構の計算を高速化し、メモリ消費を抑える専門パーツです。ComfyUIの起動オプションでも名前が出てきます。あるかないかで生成速度や使えるメモリ量が変わります。

FlashAttention

注意機構の計算を、メモリの読み書きの順番を工夫することで高速・省メモリに実行できるようにした実装方法です。計算結果自体は変わらず、同じ処理をより効率的に行うための工夫で、xFormersと似た目的を持ちます。

Triton

GPU用の計算コードをPython風の書き方で書けるようにする言語兼コンパイラです。最近のPyTorchの高速化機能の裏側でよく使われています。

bitsandbytes

モデルの数値を通常より少ないビット数に圧縮し、少ないメモリでも大きなモデルを動かせるようにするライブラリです。FLUXのような大きいモデルを少ないVRAMで動かす量子化処理でよく使われます。

Accelerate(Hugging Face)

複数GPUやさまざまな環境で、コードを書き換えずに動かせるようにする実行環境の橋渡し役です。1枚のGPUだけで動かしている分にはあまり意識しなくてよいものです。

🧰 周辺ツール

Einops

配列やテンソルの形を、次元の名前を書くだけで自由に並び替え・整理できるライブラリです。画像データの形状変換(例：縦横チャンネル数の順番からバッチ・チャンネル・縦横の順番への入れ替え)を短いコードで書けるようにします。地味だがソースコード中に頻出します。

Gradio

Pythonコードにボタン・スライダー・画像アップロード欄などの操作画面を数行で追加できるライブラリです。Hugging Face Spacesの多くはこれで作られています。

OpenCV

画像・動画処理の定番ライブラリです。リサイズ、色変換、輪郭検出など画像処理全般をカバーします。ControlNet用の線画・深度マップ作成の前処理でもよく使われます。

🔄 全体の処理の流れ(イメージ)

入力データ ↓ 前処理(リサイズ・正規化など) NumPy / OpenCV ↓ テンソル化 PyTorch(+ CUDA / cuDNN / Triton / xFormers / FlashAttention で高速化) ↓ テキストエンコード(プロンプト→ベクトル) Transformers(CLIP / T5などの実装) ↓ 画像・動画生成(拡散プロセス) Diffusers(UNet / DiTなどのパイプライン) ↓ 重みの読み書き Safetensors
