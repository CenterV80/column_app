「重み」「バイアス」「パラメータ数」を、配列のイメージでやさしく理解する

Part 1. パラメータ数の基礎まとめ（配列の例つき）

1. 入力次元 = 配列の長さ

りんごの判定タスクを例にします。写真から「赤さ・丸さ・ツヤ」の3つの特徴を数値にして、1本の配列にまとめます。

2. 重み = 入力と同じ長さの配列（1出力につき1本）

「同じ番地（インデックス）同士を掛けて、全部足す」のが重みとの計算の基本です。

3. 出力次元が増えると、重み配列も増える（→表・行列になる）

4. バイアス = 出力次元と同じ長さの配列

バイアスの数 = 出力次元数（2個）。入力の数とは無関係です。

5. 全部つなげると

出力1 = (入力配列 · 重み配列1) + バイアス[0] = 1.265 + 0.2 = 1.465 出力2 = (入力配列 · 重み配列2) + バイアス[1] = (0.9×0.1 + 0.85×-0.4 + 0.7×0.6) + (-0.1) = (0.09 - 0.34 + 0.42) - 0.1 = 0.07

出力配列 = [1.465, 0.07]（この後、活性化関数を通して最終確率になります）

6. パラメータ数の全体式

要素 配列の形 個数
入力次元 長さ n の配列 n個（例：3）
出力次元 長さ m の配列 m個（例：2）
重み n × m の行列 n×m個（例：6）
バイアス 長さ m の配列 m個（例：2）
パラメータ数 — n×m + m
パラメータ数 = n × m + m 例：n=3, m=2 → 3×2+2 = 8個

7. 多層の場合、前の層の出力配列が次の層の入力配列になる

入力層[0.9, 0.85, 0.7]
(n=3) → 中間層[1.465, 0.07, ...] → 出力層[0.95, 0.05]
(最終確率)

中間層の出力配列が、そのまま次の層の入力配列になる

8. 用語と配列イメージの対応表

用語 配列としてのイメージ
入力次元 [赤さ, 丸さ, ツヤ] のような1本の配列
出力次元 [りんご確率, みかん確率] のような1本の配列
重み（1個） 配列の中の1つの数値（例：0.7）
重み配列（1本） 1つの出力に対応する、入力と同じ長さの配列
重み行列（全体） 重み配列が出力の数だけ並んだ表
バイアス配列 出力の数と同じ長さの配列
Part 2. りんごの判定AI：入力から結果までの全体フロー

ゴール：「写真に写っているのは、りんごか、みかんか？」を判定するAIを、Part 1で出てきた配列・行列の計算だけで組み立てます。

1 特徴を数値化して入力配列を作る

入力配列と、それぞれの重み配列を「同じ番地同士掛けて、全部足す」：

出力1の計算： 0.9×0.7 + 0.85×0.5 + 0.7×0.3 = 0.63 + 0.425 + 0.21 = 1.265 出力2の計算： 0.9×0.1 + 0.85×(-0.4) + 0.7×0.6 = 0.09 - 0.34 + 0.42 = 0.17
3 バイアスを足す
バイアス配列 = [0.2, -0.1] 出力1 = 1.265 + 0.2 = 1.465 出力2 = 0.17 + (-0.1) = 0.07
4 活性化関数を通す

まだ生の数値なので、確率らしく0〜1の範囲に整えます（シグモイド関数など）。

出力1（りんご） = シグモイド(1.465) ≒ 0.81 出力2（みかん） = シグモイド(0.07) ≒ 0.52
5 結果を比較して判定
りんご確率 0.81 > みかん確率 0.52 ↓ 「これはりんごです」と判定

パラメータ数の確認

入力次元 n = 3（赤さ、丸さ、ツヤ） 出力次元 m = 2（りんご、みかん） 重みの数 = n × m = 3 × 2 = 6 バイアスの数 = m = 2 パラメータ数 = 6 + 2 = 8個

この8個のパラメータの正体

パラメータ 値 役割
重み（りんご用×赤さ） 0.7 赤いほどりんごらしいと判断する強さ
重み（りんご用×丸さ） 0.5 丸いほどりんごらしいと判断する強さ
重み（りんご用×ツヤ） 0.3 ツヤがあるほどりんごらしいと判断する強さ
重み（みかん用×赤さ） 0.1 赤さはみかん判定にあまり影響しない
重み（みかん用×丸さ） -0.4 丸すぎるとみかんらしくないと判断（マイナス）
重み（みかん用×ツヤ） 0.6 ツヤがあるほどみかんらしいと判断する強さ
バイアス（りんご用） 0.2 りんごと判定されやすい基本的な傾向
バイアス（みかん用） -0.1 みかんと判定されにくい基本的な傾向
  • これら8個の数値こそが、AIが学習によって見つけ出す「パラメータ」であり、この数値の組み合わせが「りんごとみかんを見分ける知識」そのものです。
  • 実際の画像認識AIでは、この特徴の数が数百万〜数十億に膨れ上がりますが、やっていることの本質（掛けて、足して、活性化関数を通す）は、このりんごの例と全く同じです。
