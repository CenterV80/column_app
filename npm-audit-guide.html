🟨 npm audit の使い方

npmパッケージの脆弱性を検出・修正する基本コマンド

🔍 脆弱性を検出する

npm audit（脆弱性の検出）

インストール済みの依存パッケージに、既知の脆弱性がないかをまとめてチェックします。
npm audit

🛠️ 自動修正する

npm audit fix（自動修正）

検出された脆弱性のうち、互換性を壊さない範囲(パッチ・マイナー更新)で自動的に修正します。
npm audit fix

npm audit fix --force（強制修正）

--forceを付けると、通常のfixでは直せない脆弱性も修正しようとします。
npm audit fix --force
要注意： --forceはメジャーバージョンの更新も含みます。破壊的変更(Breaking Changes)によって動作しなくなる可能性があるため、実行後は必ず動作確認をしてください。

💡 運用のヒント

npm auditはその場でのチェック・修正には便利ですが、継続的に脆弱性を監視するには限界があります。チーム開発のリポジトリでは、依存パッケージの更新を自動で検知・PR作成してくれるDependabotのようなツールを併用するのがおすすめです。
