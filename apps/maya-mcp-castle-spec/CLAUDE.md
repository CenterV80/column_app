# 日本の城（白壁・姫路城系）制作プロジェクト

あなたはMaya MCPとComfyUI MCPを使って、参照画像をもとに日本の城（白壁・姫路城系）を作る。
目的は「AIに任せられる作業」と「人が必要な作業」を切り分けること。うまくいかなかった点も成果なので、隠さずに報告する。

## 作業の進め方

- 作業は段階ごとに依頼される。1ステップごとに結果を報告して止まり、次の指示を待つ
- 作業前に必ずシーンを保存する
- 失敗や手直しが必要な箇所は、隠さずに報告する
- 各ステップの最後に評価用カメラ5台で `playblast` を撮影して確認し、問題点を報告する
- 範囲はモデリング、テクスチャ生成と割り当て、瓦配置、ビューポート評価まで。リグ・アニメーション・最終レンダーには手を出さない

## スケールと形状

- 単位はcm。天守の高さは約3000cm
- 1パーツ＝1メッシュで分ける。ポリゴン数の上限は設けない
- 形は次の順で育てる
  1. 箱組み版：台形の石垣、三層の天守（上ほど小さい箱）、各層に寄棟の屋根（壁から少しはみ出す）
  2. 城らしさを足す：屋根の反り、入母屋・千鳥破風、窓
  3. 仕上げ：石垣の反り（扇の勾配）、鯱などの装飾。できなければ限界として報告する

## 命名とフォルダ

| 対象 | 命名 | 例 |
| --- | --- | --- |
| メッシュ | `castle_{部位}_geo` | `castle_roof01_geo` |
| マテリアル | `castle_{素材}_mtl` | 素材は stone / plaster / wood / tile |
| テクスチャ | `castle_{素材}_{albedo\|height\|rough}.png` | `castle_stone_albedo.png` |

- テクスチャは `project/textures/` に保存する（Mayaプロジェクトのsourceimagesに指定済み）
- 評価ログ（各回の画像・点数・修正内容）は `project/log/` に保存する

## マテリアル

- シェーダーは `aiStandardSurface` で統一し、Arnoldで確認する
- 接続：Albedo → `baseColor`、Height → `bump2d` → `normalCamera`、Roughness → `specularRoughness`
- UVはテクスチャ1枚＝実寸2m四方で1タイルになるように合わせる

## テクスチャ生成（ComfyUI MCP）

- 指定できる入力はプロンプト（可変部分）、シード、出力名、解像度の4つのみ
- 固定プロンプトはワークフロー側に入っているので、可変部分だけを渡す
- 素材ごとの可変プロンプト

| 素材 | 可変プロンプト |
| --- | --- |
| stone（石垣） | `Japanese castle stone wall, tightly fitted granite blocks, uchikomi-hagi style, weathered gray stone, moss in the gaps` |
| plaster（白漆喰） | `white Japanese plaster wall, smooth lime plaster, subtle stains and faint weathering` |
| wood（木部） | `dark aged wood, Japanese castle timber, straight vertical grain` |
| tile（瓦1枚の質感） | `dark gray fired clay surface, Japanese roof tile, subtle glaze and weathering` |

## 瓦の配置

- 瓦はテクスチャではなく1枚ずつのジオメトリにし、Pythonの配置ツールで**インスタンス**として並べる（数千〜数万枚になるため複製は使わない）
- 丸瓦と平瓦から始める。余裕があれば軒瓦（巴紋）と棟瓦を追加する
- 屋根面の勾配方向に列を作り、平瓦と丸瓦を交互に並べる
- パラメータ：列の間隔、重なり量、ランダム回転、ランダム位置ズレ、色ムラ用のランダムID
- 平面屋根で動かしてから、反った面に沿わせて法線に合わせて向きを変える形に広げる
- まず屋根1面で試し、問題なければ全屋根に適用する
- パラメータを変えて再配置でき、他の屋根にも使えるツールとして残す
- 配置後は各瓦と屋根面の距離をレイキャストで測り、許容値を超えた瓦をリストにして報告する

## 評価と再現ループ

- 評価用カメラは固定5台：正面、側面、俯瞰、斜め45°、軒先アップ。加えて参照画像と同じ構図のカメラ1台
- 撮影は `playblast` で1フレームをPNG出力する（Maya MCPにキャプチャ機能があればそれを使う）
- 採点は5項目×10点（合計50点）：シルエット、プロポーション、屋根の形と反り、瓦の並び・密度、素材感・色
- 画像で見るチェック項目
  - 瓦の浮き・めり込み、向きの逆転、列のずれ、隙間
  - テクスチャの継ぎ目や引き伸ばし
  - 全体のプロポーション
- 全体の見た目は画像、細かい精度（瓦の浮きなど）は数値チェックで判断する
- ループは「制作 → 撮影 → 比較 → 採点 → 修正」
  - 40点以上で完了
  - 最大10回、または3回連続で点数が改善しなければ停止して報告する
  - 修正案を出したら、人の確認を待ってから再制作する
- 自己採点は甘くなりがちなので、点数は参考値として扱い、最終判断は人に委ねる

## 報告

報告では「AIだけでできた作業」と「人の手が必要だった作業」を分けて書く。あわせて次を残す。

- 問題を見つけたのがAIか人か
- ループの回数ごとの点数推移
- 瓦配置ツールを他の屋根でも再利用できるか
