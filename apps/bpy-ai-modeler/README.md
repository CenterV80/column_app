# AIモデル生成（bpy × three.js）

「作りたいもの」を書くだけで、手作業でモデリングしたような四角ポリゴン主体のメッシュを作り、
FBX / OBJ / GLB で受け取るツール。

```
作りたいもの ─▶ AI がスクリプトを書く ─▶ Blender（GUIなし）で実行 ─▶ トポロジー検査
                     ▲                                                │
                     └──── エラー・Nゴン・三角形が多い等があれば直させる ◀┘
                                                                      ▼
                                              three.js でプレビュー ＋ FBX/OBJ/GLB
```

## セットアップ

`bpy` は Blender のバージョンごとに対応する Python のバージョンが決まっています。
PyPI の bpy のページで確認して、その Python で仮想環境を作ってください（例：3.11）。

```bash
uv venv --python 3.11
source .venv/bin/activate        # Windows: .venv\Scripts\activate
uv pip install -r requirements.txt

export ANTHROPIC_API_KEY=sk-ant-...   # Windows: set ANTHROPIC_API_KEY=...
```

任意の設定:

| 環境変数 | 既定値 | 内容 |
|---|---|---|
| `CLAUDE_MODEL` | `claude-sonnet-5-5` | 使うモデル |
| `MAX_ATTEMPTS` | `4` | 直させる回数の上限 |
| `PORT` | `8000` | ポート |

## 起動

```bash
python server.py
```

http://127.0.0.1:8000 を開く。

## 使い方

1. 作りたいものを書いて「作る」（寸法や形の特徴を書くほど狙いどおりになります）
2. あとは自動で、書く → 実行 → 検査 → 直す、を最大 `MAX_ATTEMPTS` 回まわします
3. 結果をプレビューで確認（ワイヤーは三角形分割前の、本来の四角ポリゴンの辺を表示）
4. 気に入らなければ「今の結果を元に手直し」にチェックを入れて、直したい点を書いてもう一度「作る」
5. FBX / OBJ / GLB で書き出し

## トポロジー検査の基準

次のどれかに当てはまると、AI に直させます（`server.py` の `problems_of()` で変更できます）。

- Nゴン（5角形以上）がある
- 三角ポリゴンが全体の 10% を超える
- 3枚以上の面が共有している辺（非多様体）がある
- 孤立頂点がある

## 注意

- 生成したコードを `exec()` で実行するので、`127.0.0.1` でだけ待ち受けています。外部に公開しないでください。
- 検査はモディファイア適用後の形に対して行います。書き出しも適用後の形です。
- FBX は Blender の既定設定（メートル単位）で書き出しています。Maya では単位変換されて読み込まれます。
