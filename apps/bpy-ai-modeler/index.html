AIモデル生成（bpy × three.js）

公開: 2026-11-20 ／ 更新: 2026-11-21（APIキーを使わず、ローカルサーバーをAIに操作させる形に作り直し。部品の関数・ミリ単位の図面・図鑑のページ・断面図・実物どおりの機械部品を追加）

Blender（GUIなし）を持ったローカルサーバーを自分のPCで起動し、Claude Code などのAIに操作させて、手作業でモデリングしたような四角ポリゴン主体のメッシュを作り、FBX / OBJ / GLB / STL（ミリ）で受け取るホビー用ツールのソース一式です。Claude の APIキーは使いません。

GitHub リポジトリを開く（CenterV80/bpy-ai-modeler）

仕組み

Claude Code に頼む→AIがbpyスクリプトを書く→ローカルサーバー（MCP）のBlenderで実行→トポロジー検査・絵で確認→AIが自分で直す→three.jsのビューアーに表示＋書き出し

できること

  • 部品の関数（qm）：箱・回転体・断面のつなぎ・管のほか、ボルト・ナット・歯車・かさ歯車・軸受・フランジ・車輪。どれも四角ポリゴンで作る
  • 検査：Nゴン・三角形の割合・法線の向きなどのトポロジーと、浮いている部品・宣言した寸法との違いを、実行のたびに数字で返す。AI はそれを見て自分で直す
  • ミリ単位の図面：qm.units("mm") で報告をミリに。正投影の絵に方眼を付けて AI に返し、ビューアーでも座標の表示と 2 点間の計測ができる
  • 図鑑のページ：qm.catalog(...) で登録した部品ごとに、線画の等角図（引き出し線つき）・寸法線つきの三面図・部品表を 1 枚ずつ描く。印刷すると 1 項目 1 ページ
  • 断面図：ビューアーの「断面」で X / Y / Z の平面を動かして切り、切り口を斜線で塗る。図鑑にも section="X" で断面図を足せる（部品ごとに斜線の向きを変え、境目に線を引く）
  • 実物どおりの機械部品：qm.cut / qm.union（ブーリアン）で、鋳物の中の通路や軸の穴まであける。qm.cad() で四角ポリゴンの検査を外す
  • F1 の部品の関数（f1）：2026 年規定の公表値（ホイールベース・タイヤ寸法・クランクの高さなど）と推定値で作る、車体以外のシャシーの部品一式。エンジンとギアボックスは実物と同じ部品の分け方（ブロックのボアやウォータージャケット、ピストンリング、デフの中のギアまで）。作例では 1,896 部品を組み立て、断面図を含む 43 項目の図鑑を描く

F1 の部品は、公表値で確かめられた寸法以外（部品の位置など）は推定です。特定のチームの車体ではありません。

動かし方

  1. git clone https://github.com/CenterV80/bpy-ai-modeler.git で取得する（git を使わないなら、リポジトリの「Code」→「Download ZIP」）
  2. uv を入れる（bpy 5.3 が必要とする Python 3.13 も uv が用意する）
  3. Windows は start.bat をダブルクリック。初回は環境づくりまで自動で行い、ブラウザでビューアーが開く
  4. AI をつなぐ（どちらか片方）
    • Claude Code：一度だけ claude mcp add --transport http bpy-modeler http://127.0.0.1:8000/mcp
    • Claude Desktop：一度だけ .venv\Scripts\python.exe setup_claude_desktop.py を実行し、アプリを再起動（サーバーはアプリが起動するので、3で開いた start.bat は Ctrl+C で止めておく）
  5. 「bpy-modeler で木製のスツールを作って」のように頼む。図鑑を作るなら「部品ごとに qm.catalog で登録して」と添え、ビューアーの「図鑑を開く」で見る

Blender を自分の PC で動かすツールなので、このページ上では実行できません。Claude Desktop からつなぐ方法や、AI が使える道具（run_script / render など）は README.md タブを見てください。
