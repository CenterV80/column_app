AIモデル生成（bpy × three.js）

公開: 2026-11-20

Blender（GUIなし）を持ったローカルサーバーを自分のPCで起動し、Claude Code などのAIに操作させて、手作業でモデリングしたような四角ポリゴン主体のメッシュを作り、FBX / OBJ / GLB で受け取るホビー用ツールのソース一式です。Claude の APIキーは使いません。

仕組み

Claude Code に頼む→AIがbpyスクリプトを書く→ローカルサーバー（MCP）のBlenderで実行→トポロジー検査・絵で確認→AIが自分で直す→three.jsのビューアーに表示＋書き出し

動かし方

  1. このフォルダ（apps/bpy-ai-modeler/）をリポジトリから取得するか、下のタブから4つのファイルをコピーして同じ構成で保存（index.html は static/ フォルダの中）
  2. bpy に対応する Python（bpy 5.3 なら 3.13）で仮想環境を作り、pip install -r requirements.txt
  3. python server.py で起動し、ブラウザで http://127.0.0.1:8000 を開く（ビューアー）
  4. Claude Code で一度だけ claude mcp add --transport http bpy-modeler http://127.0.0.1:8000/mcp
  5. Claude Code に「bpy-modeler で木製のスツールを作って」のように頼む

Blender を自分の PC で動かすツールなので、このページ上では実行できません。Claude Desktop からつなぐ方法や、AI が使える道具（run_script / render など）は README.md タブを見てください。
