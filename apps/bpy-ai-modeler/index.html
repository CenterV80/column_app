AIモデル生成（bpy × three.js）

公開: 2026-11-20

「作りたいもの」を書くだけで、手作業でモデリングしたような四角ポリゴン主体のメッシュを作り、FBX / OBJ / GLB で受け取るホビー用ツールのソース一式です。

仕組み

作りたいもの→AIがbpyスクリプトを書く→Blender（GUIなし）で実行→トポロジー検査→問題があれば直させる（最大4回）→three.jsでプレビュー＋書き出し

動かし方

  1. このフォルダ（apps/bpy-ai-modeler/）をリポジトリから取得するか、下のタブから4つのファイルをコピーして同じ構成で保存（index.html は static/ フォルダの中）
  2. bpy に対応する Python で仮想環境を作り、pip install -r requirements.txt
  3. 環境変数 ANTHROPIC_API_KEY を設定して python server.py
  4. ブラウザで http://127.0.0.1:8000 を開く

Blender を自分の PC で動かすツールなので、このページ上では実行できません。詳しくは README.md タブを見てください。
