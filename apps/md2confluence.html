column_app / utility

Markdown→Confluence

貼るだけで、新しいConfluenceエディタにそのまま貼り付けられるMarkdown形式に整えます。見出し・太字・リンク・表・コードブロックに対応。ページのURLやHTMLからも、見出し・リスト・表の構造を保ったまま変換できます。サーバー通信なし、この場で完結。

INPUT — Markdown 0 chars
STEP 1 — URLから取得を試す(対応サイトのみ)
CORS制限のため取得できないサイトも多いです。失敗したら下の手順で貼り付けてください。
STEP 2 — 取得できない場合はHTMLを直接貼り付け
OUTPUT — Markdown 

  






  # 見出し
  **text** 太字
  _text_ 斜体
  |code| コードブロック(1列の表で再現)
  `code` インラインコード
  [text](url) リンク
  |h|h| 表
  URL/HTML h1〜h6・<title>・リスト・表の構造を保持




変換は入力のたびに自動実行されます。
