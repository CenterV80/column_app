column_app / utility

Markdown→Confluence

見出し・リスト・表・コードブロックの構造を保ったまま、Confluenceに貼り付けられる形に変換します。 「書式付きでコピー」を使うと、コードブロックや表がそのままの形でConfluenceに入ります。 サーバー通信なし、この場で完結。

INPUT — Markdown 0 字
方法1 — ページをコピーして、ここに貼り付け（おすすめ）
変換したいページを開いて Ctrl+A → Ctrl+C し、下の枠内で Ctrl+V。見た目そのままの構造を取り込めます。
方法2 — URLから取得（CORSを許可しているサイトのみ）
多くのサイトはCORS制限で取得できません。失敗したら方法1をお使いください。
方法3 — HTMLソースを貼り付け
OUTPUT 

    

  






  書式付きでコピー 本物のコードブロック・表として貼り付く
  # 見出し
  **text** 太字
  `code` インラインコード
  [text](url) リンク
  |h|h| 表





  変換は入力のたびに自動実行されます。

  Confluenceの新エディタは貼り付けたHTMLを解釈するため、「書式付きでコピー」の方が忠実に再現されます。
