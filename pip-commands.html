🐍 pip コマンド一覧

Pythonのパッケージ管理でよく使うpipコマンドをまとめました

📦 基本のインストール系

pip install（インストール）

指定したパッケージをインストールします。
pip install requests
バージョン指定： pip install requests==2.31.0

pip install -r（requirements.txtから一括インストール）

requirements.txtに書かれたパッケージをまとめてインストールします。
pip install -r requirements.txt

pip install --upgrade（アップグレード）

パッケージを最新バージョンに更新します。
pip install --upgrade requests

pip uninstall（アンインストール）

パッケージを削除します。
pip uninstall requests

🔍 確認・検索系

pip list（インストール済み一覧）

現在の環境にインストールされている全パッケージを表示します。
pip list

pip show（詳細情報）

特定のパッケージのバージョンや依存関係などの詳細を表示します。
pip show requests

pip freeze（現在の環境をエクスポート）

インストール済みパッケージをrequirements.txt形式で出力します。他の環境を再現するときに使います。
pip freeze > requirements.txt

pip --version（pip自体のバージョン確認）

現在使っているpipのバージョンを確認します。
pip --version

🛠️ pip自体の管理

pip install --upgrade pip（pip自体を更新）

pipコマンド自体を最新版に更新します。
python -m pip install --upgrade pip
ポイント： Windowsでは pip install --upgrade pip だと失敗することがあるため、python -m pip ... の形が安全です。

📋 よく使うオプション早見表

オプション 意味
-r requirements.txtなどのファイルを指定
-U / --upgrade 最新バージョンにアップグレード
-e 編集可能モードでインストール（開発中のパッケージ向け）
--no-cache-dir キャッシュを使わずにインストール
--user システム全体ではなく、ユーザー環境にのみインストール

💡 仮想環境と合わせて使う

pipはプロジェクトごとに独立させた「仮想環境（venv）」の中で使うのが基本です。仮想環境なしでpip installすると、他のプロジェクトに影響してしまうことがあります。
# 仮想環境を作成 python -m venv venv # 仮想環境を有効化（Mac/Linux） source venv/bin/activate # 仮想環境を有効化（Windows） venv\Scripts\activate # 有効化した状態でpip install pip install requests
終了するとき： deactivate で仮想環境から抜けられます。
